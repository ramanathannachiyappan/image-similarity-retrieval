# Image Similarity Retrieval using ResNet50

This project demonstrates an image similarity retrieval system implemented entirely in **Google Colab**.

## 🔹 Overview
- Dataset: CIFAR-10
- Model: ResNet50 (pretrained on ImageNet)
- Feature Extraction: Deep CNN embeddings
- Similarity Metric: Cosine Similarity
- Platform: Google Colab only

## 🔹 Methodology
1. Extract deep features using ResNet50
2. Compute cosine similarity between query and dataset images
3. Retrieve top-5 most similar images


## 🔹 How to Run
1. Open the notebook in Google Colab
2. Run Cell 1 to create dataset and query image
3. Run Cell 2 to retrieve similar images

## 🔹 Result
The system successfully retrieves visually similar images based on deep feature similarity.
